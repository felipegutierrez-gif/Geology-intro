# 🪨 Solid Solutions — An Interactive Geology Chapter

An interactive, single-file web "textbook chapter" for building intuition about
minerals, rocks, and the geological processes that make them. Everything runs in
the browser — no install, no server, no dependencies.

## What's inside

The page is organized as 12 hands-on chapters:

1. **What is a solid solution?** — plain-English explanation with the fayalite ↔ forsterite spectrum.
2. **The main solid-solution series** — a slider to morph between end-members (olivine, plagioclase, alkali feldspar, pyroxene, amphibole) and watch chemistry and properties change live; quartz shown as a pure end-member for contrast.
3. **Minerals → rocks** — click a mineral to see the rocks it builds.
4. **Inside the Earth** — clickable cross-section (crust → mantle → core) with temperature and pressure.
5. **Bowen's Reaction Series** — the crystallization order of cooling magma.
6. **Rock → minerals** — pick a rock, see its mineral recipe.
7. **How did it cool?** — extrusive (surface) vs. intrusive (deep) origins.
8. **Metamorphic & sedimentary rocks** — an interactive rock cycle plus example rocks.
9. **What's it useful for?** — industrial and everyday uses of rocks and minerals.
10. **Gemstones** — price, source mineral, and formation conditions.
11. **Plate tectonics** — a world map of plate boundaries (divergent / convergent / transform) with motion arrows.
12. **The big mineral reference table** — a scrollable, sortable, searchable table of 39 minerals (including the main ore minerals for aluminium, gold, silver, copper, and more).

### Interactive features
- Composition slider for solid-solution series
- Clickable diagrams (Earth cross-section, Bowen's series, rock cycle, tectonic map)
- Hover/tap glossary tooltips for technical terms (mafic, felsic, carat, subduction…)
- Real-world photos of each rock, mineral, and gem
- A sortable/filterable reference table with a frozen first column

## How to use it

**Just open `index.html` in any modern web browser.** That's it.

- Works offline for all diagrams, sliders, and text.
- The rock/mineral/gem **photos load from Wikimedia Commons**, so an internet
  connection is needed to display those images (a styled placeholder shows if a
  photo can't load).

## A note on the data

Numbers in this chapter (densities, melting points, abundances, gemstone prices,
spreading rates, etc.) are **representative textbook figures chosen for building
intuition** — not precise laboratory measurements. Gemstone prices in particular
are rough retail ranges that vary enormously with size, color, clarity, and treatment.
